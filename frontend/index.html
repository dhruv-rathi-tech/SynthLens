ℹ️ Technical Details & Forensic Methodology ▾

Architecture Overview: FDCS-Net V4

FDCS-Net V4 is a hybrid deep neural network engineered to identify synthetic imagery across disparate generative model architectures (Midjourney, DALL·E, Stable Diffusion, GANs):

  1. Spatial Branch: Leverages an ImageNet-pretrained EfficientNet-B0 backbone to capture high-level semantic inconsistencies and unnatural physical textures.
  2. Color Stability Branch: Evaluates high-frequency perturbation resistance via depthwise convolutions on quantized color channels, exposing synthetic color distribution artifacts.
  3. Frequency Branch: Computes a log-scaled 2-D Fast Fourier Transform (FFT) magnitude spectrum to capture periodic grid fingerprints generated during transpose-convolution upsampling.
  4. Attention Fusion Layer: Branch feature embeddings are L2-normalized and passed to a learned softmax attention head to produce dynamically weighted representations.
  5. Leak-Free Decision Boundary: The classification threshold (0.80) was chosen strictly on the validation set using Youden's J statistic ($J = \text{TPR} - \text{FPR}$), ensuring completely unbiased held-out test set evaluation.
